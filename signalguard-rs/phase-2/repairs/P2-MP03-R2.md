## Goal

Introduce an explicit market-detail DTO/resource-to-view-model boundary shared by the dedicated symbol route and existing symbol popup.

The adapter/view-model layer must own:

- conversion from the existing P2-MP02 resource boundary;
- canonical `{mode, symbol}` identity preservation;
- rejection of mismatched resource identities;
- health/status text and tone derivation;
- missing-value display representation;
- market metric formatting currently repeated by route and popup;
- anomaly display-row mapping;
- stable anomaly ordering where already required by presentation.

The route and popup must consume the same explicit readonly view-model contract for the same successful market identity.

This task is not a visual redesign and not a wire-contract change.
