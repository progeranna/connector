## Availability derivation matrix

### Demo dashboard

For `GET /dashboard/summary?mode=demo`:

- response `source` is `demo`;
- every fixed deterministic Demo catalog symbol has `source = demo`;
- every Demo symbol has `availability = observed`;
- existing deterministic state, health, anomaly, ordering, and values remain unchanged.

### Live dashboard catalog construction

For `GET /dashboard/summary?mode=live`:

1. Read one current `RuntimeModeSnapshot`.
2. Treat its canonical `symbols` as the configured symbol set.
3. Read the Redis registered-symbol set once.
4. Build the canonical union of configured and registered symbols.
5. Deduplicate by canonical `Symbol` identity.
6. Sort the final Live catalog lexicographically by canonical symbol to preserve current frontend Live ordering.
7. Fetch market states for that complete union through exactly one existing bulk `get_market_states` call.
8. Do not introduce an awaited per-symbol cache `GET` loop.
9. Do not inject any fixed Demo symbol unless it is actually configured or Redis-registered in Live.

Derive each Live symbol entry exactly in this priority order:

1. `observed`
   - a valid `MarketState` is present for the symbol;
   - `state` and `health` are populated as today.
2. `awaiting`
   - no state is present;
   - the symbol is configured;
   - runtime mode is `live`;
   - runtime status is `starting`, `running`, or `switching`;
   - `state = null`, `health = null`.
3. `configured`
   - no state is present;
   - the symbol is configured;
   - runtime mode is `replay`;
   - `state = null`, `health = null`.
4. `unavailable`
   - no state is present; and
   - either the symbol is not configured, or runtime mode is `live` with status `failed`, `stopped`, or `completed`;
   - `state = null`, `health = null`.

A Redis-registered symbol with a missing state payload follows the same priority matrix: configured+active Live is `awaiting`; configured while Replay is `configured`; otherwise it is `unavailable`.

Do not infer availability from anomaly presence, timeline length, a health score, or frontend query state.
