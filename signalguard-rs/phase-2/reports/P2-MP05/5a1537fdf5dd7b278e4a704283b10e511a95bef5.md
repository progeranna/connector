## Implementation

`RedisCache::set_market_state` now serializes the payload before Redis mutation and executes one Lua script that:

1. validates the state key type is `none` or `string`;
2. validates the symbol-index key type is `none` or `set`;
3. rejects incompatible types before mutation;
4. performs `SET` for `signalguard:market_state:<SYMBOL>`;
5. performs `SADD` for `signalguard:symbols`;
6. returns success only after both mutations execute in the script.

This replaces the previous two independent Redis commands and provides both-or-neither behavior for the deterministic wrong-type failure cases required by the contract.
