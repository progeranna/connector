## Implementation

The cache API is:

```rust
get_market_states(
    &[Symbol],
) -> Result<Vec<(Symbol, Option<MarketState>)>, CacheError>
```

Redis execution uses one `MGET` for all requested state keys. The implementation preserves input order, duplicate symbols, and explicit requested-symbol association. Missing values remain `None` in their original positions. Malformed JSON and embedded-symbol mismatches fail as `CacheError::InvalidData` with the requested symbol identified. Empty input returns without a cache round trip. In-memory behavior follows the same ordering and mismatch semantics.

The Live dashboard performs one bulk cache call and then builds state/health summaries synchronously. The former awaited per-symbol `GET` loop is removed. Demo behavior, endpoint shape, missing-state `null` behavior, anomaly association, decimal serialization, Redis keys, and API cache-error mapping remain unchanged.
