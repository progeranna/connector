## Implementation summary

The branch introduces shared symbol-owned query identities and a common resource layer for the route and popup surfaces.

Exact existing endpoint families adopted:

- `GET /market/{symbol}/state` — Live symbol state.
- `GET /market/{symbol}/health` — Live symbol health.
- `GET /market/{symbol}/timeline?mode=demo|live` — mode-aware symbol timeline; Demo timeline anomalies are used without Live fallback.
- `GET /anomalies?symbol={symbol}&limit=50` — Live symbol-filtered anomalies.

Query-key families introduced or retained:

- market state: `["market", "state", mode, canonicalSymbol]`;
- market health: `["market", "health", mode, canonicalSymbol]`;
- market timeline: `["market", "timeline", mode, canonicalSymbol]`;
- market anomalies: `["market", "anomalies", mode, canonicalSymbol, limit]`;
- dashboard summary remains mode-wide: `["dashboard", "summary", mode]`.

Live route and popup resources compose the existing state, health, and filtered-anomaly responses. Demo route and popup resources retain Demo summary state/health and use the mode-aware Demo timeline for symbol anomalies; no Live endpoint is enabled for Demo. Response symbols are checked against the requested canonical identity before a success resource is returned.
