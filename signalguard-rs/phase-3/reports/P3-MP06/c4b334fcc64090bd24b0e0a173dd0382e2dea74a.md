## Binding price-domain behavior

For empty input, `buildTimelinePriceDomain` returns exactly:

```text
[0, 1]
```

For non-empty input, it obtains the global minimum and maximum price across all points without sorting and without assuming input order:

```text
low = minimum price across every point
high = maximum price across every point
range = Math.max(high - low, 0.0001)
magnitude = Math.max(Math.abs(low), Math.abs(high))
padding = Math.max(range * 0.08, magnitude * 0.002, 0.01)
result = [low - padding, high + padding]
```

The formula is preserved exactly. There is no rounding, clamping to zero, formatting, mutation, DTO normalization, or first/last-point shortcut.

Verified examples:

- prices `100, 120` -> range `20`, padding `1.6`, domain `[98.4, 121.6]`;
- price `0` -> padding `0.01`, domain `[-0.01, 0.01]`;
- price `10` -> magnitude padding `0.02`, domain `[9.98, 10.02]`;
- prices `-200, -100` -> range padding `8`, domain `[-208, -92]`;
- prices `-10, 20` -> range padding `2.4`, domain `[-12.4, 22.4]`.

Out-of-order and duplicate prices preserve the same global min/max policy.

Every successful result is finite and strictly ascending. If finite normalized values produce non-finite or non-ascending derived bounds through numeric overflow, the function throws exactly:

```text
RangeError: timeline price domain exceeds finite numeric bounds
```

## Binding time-domain behavior

`buildTimelineTimeDomain` always receives `emptyAnchorMs` explicitly. The production source never calls `Date.now()`, constructs a zero-argument `Date`, reads a timer, or derives current time internally.

Empty input:

```text
[emptyAnchorMs - 60_000, emptyAnchorMs]
```

The empty anchor and both resulting bounds must be finite and strictly ascending. Invalid or overflowing empty anchors throw exactly:

```text
RangeError: timeline empty time-domain anchor must produce finite bounds
```

One point or any number of points sharing one timestamp:

```text
[timestampMs - 60_000, timestampMs + 60_000]
```

Multiple distinct timestamps, including out-of-order input:

```text
[global minimum timestampMs, global maximum timestampMs]
```

For non-empty input, `emptyAnchorMs` is ignored for domain selection, including when the supplied anchor is non-finite.

Point-derived overflow or non-ascending bounds throw exactly:

```text
RangeError: timeline time domain exceeds finite numeric bounds
```

The implementation does not sort, deduplicate, rewrite, or mutate timestamps or points.
