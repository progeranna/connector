## Data Age boundaries and validation

The classifier accepts exactly:

- `ageMs: number | null`;
- `delayedAfterMs: number`;
- `staleAfterMs: number`.

Classification is deterministic and exact:

- `ageMs === null` → `no_data`;
- `ageMs < delayedAfterMs` → `fresh`;
- `delayedAfterMs <= ageMs < staleAfterMs` → `delayed`;
- `ageMs >= staleAfterMs` → `stale`.

Tests cover zero, the value immediately below each boundary, both exact boundaries, values above the stale boundary, and equal delayed/stale thresholds. Equal thresholds are accepted without correction: values below the threshold are `fresh`, and the exact threshold is `stale`.

Validation rejects deterministically:

- negative age;
- non-finite age;
- negative delayed threshold;
- non-finite delayed threshold;
- negative stale threshold;
- non-finite stale threshold;
- `delayedAfterMs > staleAfterMs`.

Thresholds are validated even when `ageMs` is `null`; invalid configuration is never silently accepted or corrected. Stable `TypeError` or `RangeError` classes and messages are tested.
