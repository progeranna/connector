## Stage 0 regression coverage

The replacement regression is named:

`TimelinePanel deterministic ownership and scope > does not attribute React renderer Date.now calls to the component`

It reproduces the previous failure condition by spying on global `Date.now` while mounting the component through React Testing Library. Unlike WEB2, it does not assert that the complete renderer lifecycle makes zero calls. It:

1. supplies identical frozen component inputs and explicit `emptyAnchorMs`;
2. changes the value returned by global `Date.now` between renders;
3. confirms renderer calls occurred, demonstrating why the WEB2 zero-call assertion was invalid;
4. proves chart data, time domain, and price domain are identical across the changed clock values;
5. proves the input graph remains byte-equivalent after rendering;
6. retains a direct production-source guard forbidding `Date.now()`, zero-argument `new Date()`, timers, randomness, storage, network access, and other forbidden ownership.

The old assertion fails under the rejected WEB2 test environment because React/testing infrastructure calls `Date.now`. The replacement behavioral assertion passes while still proving that current time cannot affect component output.
