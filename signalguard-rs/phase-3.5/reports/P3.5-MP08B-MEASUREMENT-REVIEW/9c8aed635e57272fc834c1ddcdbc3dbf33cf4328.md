## Accepted ownership boundary

`TimelinePanel` remains eager and retains:

- Timeline shell and stable dimensions;
- selected market, source, status, and snapshots;
- summary/timeline loading precedence;
- unavailable, error/retry, normalized-empty, and observed states;
- normalization;
- exact domains from `buildTimelineDomains`;
- visible-anomaly derivation;
- query and selected-symbol ownership.

`TimelineChartRenderer` owns only:

- native SVG rendering;
- path and fill presentation;
- axes, tick labels, and grid;
- marker rendering;
- pointer and keyboard tooltip interaction;
- chart-specific formatting;
- responsive chart-area behavior.

`timelineChartGeometry` is a pure helper owning only projection, ticks, line paths, and fill paths. It owns no React, browser, query, clock, or data-fetching state.

## Accepted visual differences

The following bounded differences are explicitly accepted for implementation:

- a straight dependency-free polyline replaces Recharts monotone interpolation;
- native SVG tick placement may differ slightly;
- CSS-sized HTML tick labels replace view-box-scaled SVG labels to preserve mobile readability.

No other visual redesign, product-copy change, shell/layout change, status/snapshot change, marker semantics change, or route change is authorized.

The measurement did not claim pixel parity. Desktop and mobile screenshot comparison found bounded differences while the chart card dimensions, green stroke/fill, axes, grid, markers, badges, snapshots, and surrounding dashboard composition remained aligned.
