## Bundle policy

Production Vite builds now emit the deterministic manifest at `dist/.vite/manifest.json` without changing application JavaScript content or bytes.

- Initial JS is the normalized-path union of every JavaScript manifest entry and all records recursively reachable through static `imports` only. `dynamicImports` do not enter the initial closure unless the same record is statically reachable.
- Largest JS is the largest emitted `.js`, `.mjs`, or `.cjs` file under `dist/assets`; lexical asset ordering supplies deterministic tie behavior.
- Total JS is every recursively discovered `.js`, `.mjs`, and `.cjs` file under `dist/assets`, including dynamic and otherwise unreferenced files.

Normalized paths and report rows are deduplicated and sorted lexically. The checker fails clearly for missing/malformed/inconsistent/cyclic manifests, missing referenced records or emitted files, malformed/non-object/invalid budgets, absent or zero-byte JavaScript assets, and each independently exceeded budget. Failure output records metric, relevant asset, actual, allowed, and excess bytes.

The exact budgets are:

- initial: `409600` bytes;
- largest: `409600` bytes;
- total: `414720` bytes.

`npm run bundle:check` deterministically runs the built-in Node policy suite first and the real `dist` checker second.
