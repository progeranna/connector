### 7.3 Canonical market status label

The integrated tree still contains the same market-status mapping in several callers, but `marketHealthPresentation.ts` lacks a general owner.

Add one focused pure export to `marketHealthPresentation.ts` with a general argument contract suitable for Dashboard and later callers. Prefer an explicit API equivalent to:

```ts

  availability,
  healthStatus,
): string
```

The exact type shape may differ if a cleaner existing union can be reused without widening ownership.

Required output matrix:

- `configured` -> `Configured`;
- `awaiting` -> `Awaiting data`;
- `unavailable` -> `Unavailable`;
- `observed` -> `statusLabel(healthStatus)`;
- observed missing status therefore remains `Unknown`.

Use the new canonical helper from `DashboardPage.tsx` and remove the page-local `marketStatusLabel` definition.

Do not migrate desktop/mobile preview or Timeline callers in this task. Their paths are outside the lease.
