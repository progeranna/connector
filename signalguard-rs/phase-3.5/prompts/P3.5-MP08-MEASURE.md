## 7. Mandatory prototypes

Restore the exact base before each prototype. Do not stack unrelated prototypes.

### Prototype C1 — lazy entire `TimelinePanel`

Temporarily replace the static `DashboardPage → TimelinePanel` edge with a contract-safe lazy boundary and deterministic Suspense fallback.

Purpose:

- establish an upper-bound measurement for moving the entire Timeline module out of the initial graph;
- measure the UX and contract cost of deferring the whole Timeline shell.

This prototype is not automatically implementation-worthy. It must be rejected if it hides or changes accepted summary loading, timeline loading, unavailable, error, empty, snapshot, or shell behavior.

### Prototype C2 — split only the Recharts-backed renderer

Create a temporary chart-renderer module that owns only the Recharts imports and chart-specific JSX.

Keep eager in `TimelinePanel`:

- Timeline shell and section wrappers;
- symbol/source/status presentation;
- snapshot metrics;
- availability handling;
- summary loading;
- timeline error and retry behavior;
- timeline loading skeleton;
- empty state;
- normalization and domain decision ownership unless measurement proves a safer boundary;
- query ownership in `DashboardPage`.

Load the chart renderer only for the accepted observed, non-error, non-loading, nonempty chart state.

Use deterministic loading UI that preserves layout dimensions and does not produce duplicate queries, remount loops, state flicker, or repeated dynamic imports.

### Prototype C3 — renderer API alternatives

Measure at least two contract-safe module interfaces where feasible:

1. pass normalized points, anomalies, and derived domains into the lazy renderer;
2. pass raw timeline inputs and keep normalization/domain derivation inside the lazy renderer.

Prefer the interface that minimizes eager bytes without duplicating logic or changing deterministic ownership. Reject an interface that creates duplicate normalization, domain calculation, anomaly filtering, or test ownership.

### Prototype C4 — controlled inert-renderer delta

Temporarily replace only the Recharts-backed renderer with an API-compatible inert renderer while preserving all Timeline state branches and shell behavior.

Use the final-asset delta as an upper bound for the complete chart-renderer/Recharts chain. Do not label it as a pure Recharts-only byte count.
