## 6. Measurement question

Determine, with executable and browser evidence, whether the Recharts-backed Timeline chart can be replaced by a dependency-free native SVG renderer that:

- preserves the accepted Timeline shell and all non-chart state ownership;
- preserves current visible behavior and visual presentation closely enough for implementation;
- preserves timeline domains, points, anomaly markers, tooltip semantics, formatting, responsive layout, and accessibility;
- preserves Demo/Live and selected-symbol isolation;
- introduces no duplicate data requests or remount loops;
- removes Recharts and its surviving transitive graph from the production bundle;
- reduces total raw JS to at most `753664` bytes, thereby reaching the Phase 3.5 minimum headroom target;
- does not raise any budget or weaken any gate.

Static reasoning or an inert placeholder is insufficient.

## 8. Required prototype S1 — eager native SVG renderer

Build a temporary, production-quality native SVG chart prototype with no new runtime dependency.

Preferred ownership:

- eager `TimelinePanel` retains shell wrappers, symbol/source/status, snapshots, availability, summary loading, timeline loading/error/retry, normalized-empty, normalization, domains, visible-anomaly derivation, selected-market identity, and query ownership;
- a renderer module owns SVG geometry, path construction, axes/ticks, gradient/fill, anomaly marker lines, pointer interaction, tooltip positioning/content, responsive sizing, and chart-specific formatting.

The prototype may use browser and React primitives only. It must not use Recharts, D3, another chart library, Canvas, WebGL, or a new runtime dependency.

`web/src/features/dashboard/TimelineChartRenderer.tsx`
