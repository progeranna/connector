## S1 — eager native SVG renderer

Temporary design:

- `TimelinePanel` remained the eager owner of the shell, selected market/source/status, summary precedence, availability, timeline loading/error/retry/empty states, normalization, exact domains, visible anomaly filtering, snapshots, and query-owned props.
- `TimelineChartRenderer.tsx` was statically imported and owned only native SVG geometry, line/fill paths, axes/ticks, grid, anomaly marker lines, pointer/focus tooltip interaction, formatting, and the fixed 285px chart area.
- The renderer used browser/React primitives only: SVG, React state, keyboard focus, and pointer events. No Recharts, D3, Canvas, WebGL, or new dependency was used.
- The initial version used a simple polyline. This is visually close to the existing monotone Recharts presentation but is not an exact interpolation reproduction.

## S2 — native renderer plus pure geometry helper

S2 retained the S1 ownership boundary and extracted pure geometry into:

```text
web/src/features/dashboard/TimelineChartRenderer.tsx
web/src/features/dashboard/timelineChartGeometry.ts
```

The helper owns only stable view-box constants, domain projection, evenly spaced ticks, line-path construction, and closed fill-path construction. It has no React, browser, query, clock, or data-fetching ownership. Temporary focused tests covered domain-boundary projection, tick endpoints, line paths, fill closure, and empty geometry.

The final corrected renderer:

- preserves the exact normalized points and `buildTimelineDomains` output supplied by `TimelinePanel`;
- receives all anomalies for tooltip matching and separately receives `visibleAnomalies` for marker rendering;
- keeps inclusive `Math.abs(anomalyTime - point.timestampMs) <= 15_000` matching;
- renders green stroke, gradient fill, horizontal dashed grid, Time/Price labels, severity-colored vertical markers, stable dimensions, and fixed no-animation behavior;
- provides `role="img"`, an accessible chart label, keyboard focus, left/right point navigation, Escape dismissal, and focus tooltip content;
- uses an HTML overlay for tick text so mobile CSS font size is not distorted by SVG view-box scaling.
